# Plan - Both Ready

## Goal

Ship a free offline pose a child and a grandparent do together. The next pose waits until both have tapped ready. The phone keeps the place.

## Approach

1. App Store Connect has no rejected version waiting.
2. Build Both Ready in Expo: six poses, two ready taps, and a saved place.
3. Run the full simulator regression on the Release binary for build 1.
4. Take three native screenshots, then upload that binary and submit it.

## Why this app

Picture lists, outing plans, dice, dinner answers, household places, tapped sentences, copy-the-line, room hunts, and shape pairs are already in this pipeline. Family photo apps already fill the store. This one has no camera. Both people tap ready before the pose changes.
